# Convertoria

A modern, fast unit converter built with vanilla JavaScript. Convert across 8 categories with real-time updates, persistent history, and dark/light mode support.

## Features

**8 Conversion Categories**
- Length: Meters, Kilometers, Miles, Feet, Inches, Yards, Centimeters, Millimeters
- Weight: Kilograms, Grams, Pounds, Ounces, Tons, Milligrams
- Temperature: Celsius, Fahrenheit, Kelvin
- Area: Square Meters, Square Feet, Square Yards, Acres, Hectares, Square Kilometers
- Volume: Liters, Milliliters, Gallons, Quarts, Pints, Cups, Fluid Ounces
- Speed: KM/H, MPH, Knots, M/S, FT/S
- Time: Seconds, Minutes, Hours, Days, Weeks, Years
- Data: Bytes, Kilobytes, Megabytes, Gigabytes, Terabytes

**Core Features**
- Real-time conversion as you type
- Swap units with one click
- Copy results to clipboard
- Quick value buttons (1, 10, 100, 1000)
- Conversion history saved to localStorage
- Individual history entry deletion
- Clear all and clear history options
- Dark/Light mode with persistent preference

**Technical Details**
- Pure vanilla JavaScript
- Glass-morphism UI design
- Fully responsive
- Keyboard support (Enter to convert)
- No external dependencies
